Practice Pack: 01b Python Patterns and OOP#

Work this pack at least one day after reading the module. Write your answer before opening each solution; recognition is not retrieval.

1. Retrieval questions#

  1. When is composition preferable to inheritance?
Answer When the object uses collaborators rather than being a specialized subtype. Composition keeps the relationship replaceable and usually limits coupling.
  1. What does a generator preserve between calls?
Answer Its execution state, including local variables and the next instruction, until the next `next()` or iteration step.
  1. What must a decorator return?
Answer A callable replacement for the decorated object, unless it is deliberately being used only for registration.
  1. What is the purpose of a type hint?
Answer It communicates the intended contract to readers and static tools; normal Python does not enforce it at runtime.
  1. What makes a test independent?
Answer It controls its own inputs and state, makes one clear assertion about behavior, and does not depend on test order or external mutable state.

2. Prediction exercises#

  1. A generator contains yield 1, then yield 2. How many times does its body execute when you call the function but do not iterate?
Answer The function body does not run yet; calling it creates a generator object. The body runs as iteration requests values.
  1. A decorator wrapper calls the wrapped function but forgets return result. What does the caller receive?
Answer `None`, even though the wrapped function computed a value.
  1. A class stores a retriever instance and a formatter instance. Which relationship is that?
Answer Composition: the class has collaborators rather than inheriting from them.

3. Debugging scenarios#

  1. A retry decorator repeats a payment request after a timeout and charges twice. What design property is missing?
Answer Idempotency or an idempotency key. Retrying a side effect without making duplicate execution safe is dangerous.
  1. A context manager opens a file but an exception leaves the file open. Where should cleanup live?
Answer In the context manager's exit/finally path so cleanup runs for both success and failure.
  1. A test passes alone but fails after another test mutates a module-level list. What is the likely cause?
Answer Shared mutable test state. Create fresh fixtures or reset the state for each test.

4. Short explanation prompts#

  1. Explain why validation belongs at an external API boundary.
Answer Untrusted data should become a typed, explicit internal value once; downstream code can then rely on the contract instead of repeating defensive checks.
  1. Explain why retries need backoff.
Answer Immediate retries amplify load and synchronize callers during an outage. Backoff spreads attempts and gives a transient dependency time to recover.
  1. Explain the difference between a protocol and an implementation.
Answer A protocol states the behavior a caller may rely on; an implementation supplies the concrete behavior. Depending on the protocol makes replacement and testing easier.

5. Implementation task#

Refactor a small function that fetches documents, validates the response, and formats the result into a typed service with one injected retriever, one Pydantic boundary model, a retry policy, and tests for success, malformed data, and a transient failure.

Do not open the rubric until you have a working attempt.

6. Rubric#

  • [ ] The service has one clear public contract.
  • [ ] The retriever can be replaced by a fake in tests.
  • [ ] Malformed input fails with a useful error.
  • [ ] Retries are bounded and do not retry validation errors.
  • [ ] Tests cover behavior rather than implementation details.

7. Scoring#

  • 4 — Ready: answers are produced without notes, the implementation works, and the explanation names tradeoffs.
  • 3 — Practiced: one weak area remains; schedule a review in 7 days and redo that section.
  • 2 — Learning: revisit the module's first-pass path and retry the prediction/debugging sections tomorrow.
  • 1 — Not yet: ask for help or use the worked example, then restart with a smaller task.
