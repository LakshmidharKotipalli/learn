Practice Pack: 04 Classical Machine Learning#

Work this pack at least one day after reading the module. Write your answer before opening each solution; recognition is not retrieval.

1. Retrieval questions#

  1. What is leakage?
Answer Information from outside the allowed prediction-time boundary influences training or evaluation.
  1. Why choose a threshold separately from a model?
Answer The model estimates a score; the threshold converts it into an action with a business cost tradeoff.
  1. What does calibration measure?
Answer Whether predicted probabilities correspond to observed frequencies.
  1. When is PR-AUC more informative than ROC-AUC?
Answer Often when the positive class is rare and precision among positive predictions matters.
  1. What is drift?
Answer A change in input, relationship, or outcome distribution that can make previous model behavior unreliable.

2. Prediction exercises#

  1. A feature is selected using the full dataset before cross-validation. Why can the score be optimistic?
Answer The validation folds influenced feature selection, so information leaked across the evaluation boundary.
  1. A classifier keeps the same ranking but its positive class becomes more costly. What can change without retraining?
Answer The decision threshold, because the action costs changed even if the score ordering did not.
  1. A model has good accuracy on a 1% positive dataset but catches no positives. What does accuracy hide?
Answer The class imbalance; predicting the majority class can look accurate while having zero recall for the important class.

3. Debugging scenarios#

  1. Offline AUC is high but production precision collapses. What should you inspect?
Answer Population shift, leakage, threshold selection, label delay, and whether production prevalence differs from evaluation.
  1. Training and validation loss look identical and high. What is one likely cause?
Answer Underfitting, insufficient capacity, poor features, or an optimization/setup problem.
  1. A model score is well calibrated overall but not for a key customer segment. What is missing?
Answer Segment-level calibration analysis and possibly segment-specific handling or more representative data.

4. Short explanation prompts#

  1. Explain why the metric follows the decision.
Answer A metric is useful only if improving it improves the decision outcome; the same model can need different metrics for different costs.
  1. Explain the bias-variance tradeoff.
Answer A model that is too simple misses structure; one that is too flexible fits noise. Generalization balances those errors.
  1. Explain why a pipeline prevents leakage.
Answer Transformations are fitted inside each training fold and then applied to validation data, so validation information cannot shape the transform.

5. Implementation task#

Train a small classifier with an explicit preprocessing pipeline. Compare a deliberately leaky evaluation with an honest cross-validated evaluation, choose a threshold for a stated cost ratio, and report calibration.

Do not open the rubric until you have a working attempt.

6. Rubric#

  • [ ] The prediction-time boundary is written down.
  • [ ] Preprocessing is inside the evaluation pipeline.
  • [ ] The threshold is tied to costs, not a default of 0.5.
  • [ ] The report separates ranking, decision, and calibration metrics.
  • [ ] At least one drift signal is named.

7. Scoring#

  • 4 — Ready: answers are produced without notes, the implementation works, and the explanation names tradeoffs.
  • 3 — Practiced: one weak area remains; schedule a review in 7 days and redo that section.
  • 2 — Learning: revisit the module's first-pass path and retry the prediction/debugging sections tomorrow.
  • 1 — Not yet: ask for help or use the worked example, then restart with a smaller task.
